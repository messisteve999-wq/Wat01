# Wat01

1. Pousser ce dossier sur GitHub : GitHub Actions compile l'APK automatiquement (onglet Actions > Build Wat01 > Wat01-apk).
2. Installer l'APK, ouvrir Wat01, renseigner l'URL du serveur Gemini et les applis à synchroniser.
3. Autoriser l'accès aux notifications et la bulle flottante, puis appuyer sur "Démarrer Wat01".
